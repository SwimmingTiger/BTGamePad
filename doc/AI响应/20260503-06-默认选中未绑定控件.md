## 修改内容

### 1. 新增 `selectFirstUnboundControl()` 方法（`selectControl` 之前）

遍历 `layoutControls`，找到第一个未绑定的控件后调用 `selectControl` 选中它。如果所有控件都已绑定，则不改变选中状态。

### 2. 在 `initializeLayoutRepository()` 中调用

布局加载后，如果未能自动进入执行模式（存在未绑定控件），则自动选中第一个未绑定控件：

```typescript
this.tryAutoEnterExecutionMode();
if (!this.isExecutionMode()) {
    this.selectFirstUnboundControl();
}
```

| 场景 | 结果 |

| 存在未绑定控件 | 保持编辑模式，**自动选中第一个未绑定控件** |
| 无控件 | 保持编辑模式，不选中 |
