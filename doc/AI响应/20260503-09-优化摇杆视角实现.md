## 摇杆视角（stick-look）新行为

**原来的行为**：摇杆位置直接映射到控件区域内的固定触摸点。

**新的行为**：
1. 从控件中心（原点）出发
2. 持续向摇杆指向的方向缓慢移动（基础速度 480 单位/秒）
3. **摇杆幅度 = 移动速度**（满偏转最快，小幅度慢移）
4. **超出屏幕边界时**：自动松开触摸，回到原点继续移动（循环往复）
5. **松开摇杆时**：直接松开触摸，不回到原点

## 修改的文件

LayoutEditor.ets

### 新增常量
- `STICK_LOOK_ANIM_INTERVAL_MS = 16` — 60fps 帧间隔
- `STICK_LOOK_BASE_SPEED = 480` — 满偏转基准速度（单位/秒）

### 新增状态变量（7个私有变量）
- `stickLookAnimActive/DirectionX/DirectionY/Magnitude/CurrentX/CurrentY/ControlId/CenterX/CenterY/IntervalId`

### 新增方法
- `updateStickLookAnimation()` — 根据摇杆输入更新方向和速度
- `startStickLookAnimation()` — 启动 16ms 定时器
- `tickStickLookAnimation()` — 每帧：移动位置 → 检测边界 → 发送触摸/鼠标
- `stopStickLookAnimation()` — 停止动画并释放触摸

### 修改的方法
- `handleGamepadAxisExecutionEvent()` — 增加对 `updateStickLookAnimation` 的调用
- `updateStickExecutionTargets()` — 跳过 stick-look 控件（由动画系统接管）
- `reconcileExecutionOutput()` — 动画激活时跳过正常输出
- `resetExecutionState()` — 增加 `stopStickLookAnimation()` 清理
