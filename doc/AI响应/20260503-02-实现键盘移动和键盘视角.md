## 新增功能：键盘八向移动和键盘视角

### 核心逻辑

1. **`heldDirectionalKeys`** — 一个 `Map<number, boolean>`，跟踪当前按住的方向键。按键按下时加入，松开时移除。

2. **八向方向计算** (`getKeyboardDirectionVector`)：
   - `horizontal = (右按下 ? 1 : 0) - (左按下 ? 1 : 0)`
   - `vertical = (下按下 ? 1 : 0) - (上按下 ? 1 : 0)`
   - 归一化后得到单位方向向量
   - 自然支持 8 个方向（例如 上+右 = 45° 对角线）
   - 相反方向会自动抵消（例如 上+下 = 无移动）

3. **`updateKeyboardDirectionalTargets`** — 执行模式下的主处理方法。按键按下/松开时，找到所有使用该键的键盘移动/视角控件，计算方向向量，并更新执行目标。

4. **预定义键码映射** (`resolvePredefinedDirectionalKeyCodes`)：
   - `keys-wasd` → W(2041), A(2044), S(2042), D(2043)
   - `keys-arrows` / `keys-arrows-look` → 上(2012), 左(2014), 下(2013), 右(2015)
   - `keys-numpad-move` / `keys-numpad-look` → 8(2086), 4(2082), 2(2080), 6(2084)
   - `keys-ijkl` → I(2032), J(2035), K(2036), L(2037)

5. **`handleExecutionKeyEvent`** 已修改，先尝试方向控件更新，再处理按钮绑定。因此键盘移动/视角控件和键盘按钮控件可以在同一布局中共存。

### 工作方式

- 用户按住一个方向键 → 触控移动到该方向的控件边缘
- 用户按住两个相邻的方向键（例如 W+D） → 触控移动到 45° 对角线位置
- 用户松开所有方向键 → 触控释放
- `resetExecutionState` 在退出执行模式时清除所有按住的键

### 新增动画系统

**动画状态变量**（9 个新字段）：
- `keyboardAnimTargetX/Y` — 目标位置
- `keyboardAnimCurrentX/Y` — 当前显示位置（通过 lerp 平滑逼近目标）
- `keyboardAnimActive` — 动画是否正在运行
- `keyboardAnimIntervalId` — 16ms 间隔定时器（~60fps）

**滑行行为**：
1. 按下方向键 → 目标设为边缘位置 → 当前值以 `speed=0.28` 的速率指数衰减逼近目标 → 产生自然的缓出效果

3. 松开所有按键 → 目标设为回中 → 当前值平滑滑回圆心 → 到达后释放触摸
