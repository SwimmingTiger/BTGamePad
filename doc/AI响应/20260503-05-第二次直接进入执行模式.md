## 修改内容

在 LayoutEditor.ets 中做了两处修改：

### 1. 新增 `tryAutoEnterExecutionMode()` 方法（第 1763 行之前）

该方法在满足以下**全部条件**时自动进入执行模式：
- 当前布局至少有一个控件
- 至少有一个已绑定控件（`getBoundControlCount() > 0`）
- **所有**控件都已绑定（遍历检查，不存在未绑定控件）
- HID 设备已连接

### 2. 在 `initializeLayoutRepository()` 中调用（第 476 行）

在布局加载完成后（`refreshLayoutSummary()` 之后）调用 `tryAutoEnterExecutionMode()`，仅页面初次加载时触发，不会影响后续的布局切换操作。

### 行为说明

| 场景 | 结果 |
|------|------|
| 全部控件已绑定 + HID 已连接 | 自动进入执行模式 |
| 存在未绑定控件 | 保持编辑模式 |
| 没有已绑定控件 | 保持编辑模式 |
| HID 未连接 | 保持编辑模式 |
| 布局为空（0 个控件） | 保持编辑模式 |
